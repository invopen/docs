Invopen is a set of open-source, free, and modular pieces of software meant to aid small/medium sized businesses in stockkeeping, online order fulfillment, and more.

All but one piece of our software is optional. **Every piece of our software relies on [Orchestrator](/docs/orchestrator).**

All of our software is open-source on [Github](https://github.com/invopen), and is open to contributions.

Bugs should be reported at [bugs.invopen.app](https://bugs.invopen.app), though issues created on our various Github pages will be mirrored.

Invopen is developed by one person and help is very much appreciated.

This documentation gives you all you need to know on how to set up any of Invopen's pieces of software, even if you have very little computer knowledge. If you're interested, check out the [Getting Started guide for Orchestrator](/docs/ochestrator/getting-started).
